2kod mailer 개인정보처리방침

시행일: 2026년 11월 12일

2kod mailer는 2kod가 운영자 본인의 Gmail 계정에서 업무 메일(게임 체험판 안내 등)의 임시보관 메일을 만들고 보내기 위해 쓰는 내부 도구입니다. 일반 사용자를 대상으로 한 서비스가 아니며, 운영자 본인 계정에만 연결됩니다.

요청하는 권한

Gmail API의 gmail.compose 범위(임시보관 메일 관리와 메일 발송)만 요청합니다. 받은편지함의 메일을 읽지 않습니다.

수집·이용하는 정보

  • 인증 토큰: 운영자 컴퓨터에만 저장하며 외부 서버로 보내지 않습니다.
  • 보내는 메일의 받는 사람 주소와 본문: 운영자가 직접 작성한 것이며, 발송 목적 외에 쓰지 않습니다.

Google 사용자 데이터를 제3자에게 판매하거나 공유하지 않고, 광고에 쓰지 않으며, AI 모델 학습에 쓰지 않습니다. 2kod mailer의 Google API 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

보관과 삭제

인증 토큰은 운영자가 연결을 끊거나 Google 계정 권한 페이지에서 액세스를 취소하면 더 이상 쓸 수 없고, 운영자 컴퓨터에서 삭제합니다.
